    > 1_check 
        - [새롭게 배운 개념]
            - Scripting 방식
                + inline Scripting: HTML 태그 내에 직접 자바스크립트 코드를 작성하는 방식. 특정 framework(react,Vue)를 제외한 정규식에서는 추전되지 않음(표준 위배) 
                + inner Scripting: HTML 문서 내의 <script> 태그 안에 자바스크립트 코드를 작성하는 방식. 테스트 용도로만 사용할 것
                + outer SCripting: 자바스크립트 코드를 별도의 .js 확장자를 가진 파일로 저장하고, HTML 문서에서는 <script> 태그의 src 속성을 사용하여 파일을 연결(포함)하는 방식
            - 기명 함수(Named Function): 이름이 있는 함수
                + 이름이 있어서 인사하기(); <- 이렇게 여러 번 불러서 사용 가능
                    ex. function 인사하기() { alert("안녕하세요!"); }
            - 익명 함수(Anonymous Function): 이름이 없는 함수
                + 이름이 없기 때문에 직접적으로 그 이름을 불러서 재사용하기 어려움. 주로 다른 함수의 인자로 전달되거나, 즉시 실행하고 사라지는 용도로 많이 사용.
                    ex. setTimeout(function() { alert("3초 오버"); }, 3000);
                        + function() { ... } 부분이 익명 함수
            - 공용 함수(ribrary funcion): 미리 만들어져있는 함수
                + 브라우저나 자바스크립트 자체에 이미 만들어져 있는, 누구나 쓸 수 있는 "공용 도구" 같은 함수
                    ex. alert()와 같은 함수 (window.alert()의 줄임 표현)
            - 동기 처리(Synchronous)
                : 순서대로 처리하는 것에 가까움. 한 작업이 요청되면, 그 작업이 끝날 때까지 기다렸다가 다름 작업을 수행
                + 장점: 코드의 실행 순서가 명확하고 이해하기 쉬우며 설계가 간단
                + 단점: 하나의 작업이 오래 걸리면 전체 시스템이 멈추거나 느려짐
            - 비동기 처리 (Asynchronous)
                : 한 작업이 요청되면, 그 작업이 끝나는 것을 기다리지 않고 바로 다음 작업을 수행
                + 장점: 시간이 오래 걸리는 작업이 있어도 다른 작업을 동시에 처리할 수 있어 시스템 전체의 효율성이 높아지며, 블로킹이 발생하지 않아 사용자 인터페이스가 멈추지 않고 반응성을 유지함
                + 단점: 코드의 실행 순서가 동기 방식보다 복잡하고 이해하기 어려울 수 있음
        - [참고 개념]
            + 프로그래밍을 할 때 가장 기본이 되는 생각의 흐름
                1. 선언(Declaration): 내가 뭘 사용할 건지 알려줄게
                    ex. function 인사하기() { ... } (인사하기라는 기능을 만들 거야)
                2. 처리 (Processing): 선언한 것들을 가지고 이제 작업을 할 거야
                    ex. 인사하기(); (아까 만든 '인사하기' 기능을 실행할 거야)
                    ex. let 결과 = 숫자 + 5; (아까 만든 '숫자'에 5를 더해서 '결과'에 저장할 거야)
                3. 출력 (Output): 작업한 결과를 보여줄게
                    ex. alert(결과); (결과를 경고창으로 보여줄 거야)
            + 개발자 도구(F12)의 콘솔 창에 callAlert(즉, 함수명) 라고 치고 엔터를 누르면 function callAlert(){ alert("안농?"); } 이렇게 우리가 만든 함수의 내부를 확인할 수 있음
            + claaAlert(); 라고 함수를 입력하면 함수가 실행됨
            + 자바스크립트는 코드 중간에 문법 오류나 실행 중 처리할 수 없는 오류(Error)가 발생하면 그 지점에서 스크립트 실행이 멈춰버림

            + 스코프(Scope)
            : 변수나 함수에 접근할 수 있는 범위 또는 영역을 말함. 즉, 어떤 변수나 함수가 코드의 어느 부분에서 유효한지를 결정하는 규칙 또는 경계
            - 전역 스코프(global Scope)
                - 코드의 가장 바깥쪽 영역. 프로그램 전체 또는 모듈 전체에 걸쳐 적용되는 스코프.
                - 여기에 선언된 변수(즉, 전역 변수)나 함수는 코드 내의 어디서든(함수 내부 포함) 접근 가능
            - 지역 스코프(Local Scope)
                - 특정 코드 블록(주로 함수 내부)에 국한되는 스코프
                - 여기에 선언된 변수(즉, 지역 변수나 매개 변수)는 해당 함수 내부에서만 접근할 수 있으며, 함수 외부에서는 알 수 없고 접근도 불가능
            - 전역 변수, 지역 변수, 매개 변수
                + 그 변수가 어떤 스코프 규칙을 따르는지에 따라 붙여진 이름.
                + 특정 스코프 내에서 선언되어, 해당 스코프의 규칙을 따르는 변수 자체를 가리키는 용어 
                + 스코프는 이 변수들이 어디서 보이고 사용될 수 있는지를 결정하는 더 근본적인 개념. 
                ex. var globalVal = "전역변수";
                    window.onload=function(){
                        var localVal = "지역변수";
                        alert(localVal);
                    }

    > 3_typeof
        - [새롭게 배운 개념]
            - typeof: 주어진 값의 데이터 타입(자료형)이 무엇인지 알려주는 문자열을 반환하는 연산자
        - [참고 개념]
            - 자료형: 변수에 저장될 수 있는 데이터의 종류를 의미
                + 원시 타입(primitive Types): 값이 하나의 고정된 데이터를 나타내며, 변경 불가능한 특징을 가짐
                    - string(문자열): 텍스트 데이터를 나타내며, 작은 따옴표나 큰따옴표로 감싸서 표현
                    - number(숫자형): 정수, 소수 등의 모든 숫자 값을 나타냄
                    - boolean(논리형): 참(true) 또는 거짓(false) 값을 나타내며, 주로 조건문에서 사용됨
                        + true : 맞음, 1, 같음, 진실, 성공
                        +  false : 틀림, 0, 같지않음, 거짓, 실패
                    - undefined(미정의): 변수를 선언했지만 아직 값이 할당되지 않은 상태를 나타내는 특별한 값
                    - null: 어떤 값이 의도적으로 비어 있음을 나타내는 특별한 값. undefined와 달리 개발자가 명시적으로 "값이 없다"고 지정할 때 사용
                        + 객체를 담기 위한 변수를 초기화하는 상태
                + 객체 타입(Object Type / Reference Type): 다양한 종류의 데이터를 키(Key)와 값(Value)의 쌍으로 묶어서 저장하거나, 여러 값을 순서대로 모아놓은 컬렉션을 나타냄
                    - object(객체): 가장 기본적인 객체 형태. 중괄호({})를 사용하여 만들며, 이름(키)과 값으로 구성된 속성(Property)들을 가짐
                    - array(배열): 여러 개의 값을 순서대로 나열하여 저장하는 객체의 특별한 형태. 대괄호([])를 사용하여 만듦 
                        + typeof 배열은 "object"를 반환함. 배열인지 정확히 확인하려면 Array. isArray(배열변수) 메서드를 사용하는 것이 좋음
                    - funcion(함수): 특정 작업을 수행하는 코드 블록. 함수도 JavaScript에서는 객체의 한 종류로 취급됨

    > 4_typeofchange
        - [새롭게 배운 개념]
            - 형변환: 데이터의 타입을 다른 타입으로 변환하는 과정
                + 사용하는 경우: 프로그램에서 서로 다른 타입의 데이터를 연산하거나, 특정 타입의 변수에 다른 타입의 값을 저장해야 할 때 사용
            - 형변환의 종류
                + 암시적 형변환: 컴파일러가 자동으로 데이터 타입을 변환
                    a. 숫자 + 문자 = 문자
                    b. 불린 + 숫자 = 숫자
                    c. 불린 + 문자 + 문자
                + 명시적 형변환: 개발자가 코드에 직접 lib core function을 이용하여 강제로 데이터 타입을 변환
                    - to숫자 형변환 함수
                        + Number(value)
                            : 명시적 숫자 형변환 함수로, 전달된 value를 숫자(number) 타입으로 변환하는 전역 함수
                            - 숫자 형태의 문자열(ex: "123", "3.14")이 해당 숫자로 변환
                        + parseInt()
                            : 정수형 변환. 주어진 문자열의 시작 부분부터 분석하여 정수(integer)를 반환. 문자열의 첫 번째 문자가 숫자로 변환될 수 없다면 NaN (Not a Number)을 반환
                        + parseFloat()
                            : 실수형 변환. 주어진 문자열의 시작 부분부터 분석하여 실수를 반환.
                        + Number와 parse의 차이 
                            1. Number(): 입력값 전체가 유효한 숫자 형식인지 더 엄격하게 검사하며, 다양한 타입(null, boolean 등)에 대한 변환 규칙을 가짐
                            2. parse 계열: 문자열의 앞부분부터 순차적으로 읽으면서 숫자로 변환 가능한 부분까지만 처리. 즉, 문자열 전체를 엄격하게 검사하지 않음.
                                + parse는 문자열의 일부만 숫자여도 그 부분까지는 변환이 가능. 이것이 Number() 함수와의 중요한 차이점 (Number("123xyz")는 NaN을 반환)

                    - to문자 형변환 함수
                        + String(value): 명시적 문자열 형변환 함수로, 전달된 value를 문자열(string) 타입으로 변환하는 전역 함수
                            - 대부분의 값을 그에 상응하는 문자열 표현으로 변환 (ex. 123 -> "123", true -> "true")
                        + Number.toString(): Number 객체의 프로토타입에 정의된 함수로, 숫자 값을 문자열 표현으로 변환
                            - 가장 큰 특징은 선택적으로 진법(radix)을 지정하여 해당 진법의 문자열로 변환할 수 있다는 것
                            - 생략하거나 10을 전달하면 10진수 문자열로 변환, 2를 전달하면 2진수 문자열로 변환, 8을 전달하면 8진수 문자열로 변환, 16을 전달하면 16진수 문자열로 변환
                        + number.toFixed(): .toFixed 또한 Number 객체의 프로토타입에 정의된 함수로, 소수점 이하의 자릿수를 지정하여 그 자릿수만큼만 표시하고, 필요하다면 반올림을 수행
        - [참고 개념]
            - 함수는 기본적으로 폐쇄적인 형태 
            - 결과를 담는 변수와 처리를 담당하는 변수가 다른 게 일반적
            - console.log는 콘솔창에 띄워줄게. 이렇게 이해하기. 
                + 실무에서 console.log는 확인했으면 지워야함
            - var result=2+true; 원래 개발할 때는 띄어쓰기를 하면 안 됨(쓸데없이 용량을 낭비하는 행위) - 확장자 프리티어 이용할 것
            - 변수명 지정 시 주의사항 
                + 코드 전체적으로 어떤 값을 나타내는 변수명이 관례적으로 정해져 있거나 목적성이 분명한 경우가 아니라면, 설령 스코프가 다르더라도 같은 이름은 사용하지 않는 것이 가독성과 유지보수 측면에서 좋음
            - 소수 반올림
                + 개발에서는 모든 숫자 처리에서 자동으로 반올림이 적용되는 것은 아님. parseInt()처럼 그냥 버리는 경우도 있지만, 어떤 연산 결과로 소수 부분이 생겼을 때, 이 소수 부분을 어떻게 처리할지(올릴지, 내릴지, 반올림할지)는 개발자가 해당 기능을 수행하는 함수(Math)를 사용해서 지정해야함.

                + /	: 나눗셈
                + %	: 나머지
                + ** : 거듭제곱
                + 복잡한 표현식에서는 괄호 ()를 사용하여 명시적으로 연산 순서를 지정하는 것이 가독성을 높이고 의도치 않은 오류를 방지하는 데 도움을 줄 수 있음    
            - 증감 연산자(중요)
                + ++ : 1 증가 ++a (전위), a++ (후위)
                + -- : 1 감소 --a (전위), a-- (후위)
                + 피연산자의 앞(전위) 또는 뒤(후위)에 위치할 수 있으며, 이에 따라 값의 평가 및 변경 시점이 달라짐
                    - 전위 증가 연산자 (++a) 동작: 변수 값을 먼저 1 증가시킨 후, 그 증가된 값을 사용(출력)
                    - 후위 증가 연산자 (a++) 동작: 변수 값을 먼저 사용(출력)한 후, 변수 값을 1 증가
            - 할당 연산자 (Assignment Operators)
                + 복합 할당 연산자: 산술 연산과 할당을 결합하여 코드를 간결하게 만듦
                + = : 기본 할당 (오른쪽 피연산자의 값을 왼쪽 피연산자에 할당)
                + += : 기존 변수의 값에 값을 더한 후 할당
                + -= : 기존 변수의 값에 값을 뺀 후 할당
                + *= : 기존 변수의 값에 값을 곱한 후 할당
                + /= : 기존 변수의 값에 값을 나눈 후 할당
                + %= : 기존 변수의 값에 나머지를 구한 후 할당
                + **= : 거듭제곱 연산 후 할당
            - 비교 연산자 (Comparison Operators)
                + 두 피연산자의 값을 비교하여 불리언(true 또는 false) 값을 반환
                + == : 좌변 우변 동등 (값만 비교, 타입 변환 발생 가능)
                + != : 좌변 우변 부동등 (값만 비교, 타입 변환 발생 가능)
                + === : 일치 (값과 타입 모두 비교, 타입 변환 없음)
                + !== : 불일치 (값과 타입 모두 비교, 타입 변환 없음)
                + > : 초과 (좌변이 큼)
                + < : 미만 (우변이 큼큼)
                + >= : 이상 (좌변이 우변보다 크거나 같음)
                + <= : 이하 (우변이 좌변보다 크거나 같음)
            - 논리 연산자 (Logical Operators)
                : 불리언 값을 사용하여 논리적인 연산을 수행하거나, 피연산자 중 하나의 값을 반환
                + && : AND (다중 조건 모두 true일 경우 true 반환)
                + || : OR (다중 조건 중 하나만 true를 충족해도 ture 반환)
                + ! : 논리 부정 연산자 NOT (참을 거짓으로, 거짓을 참으로. 불리언 값을 반전시킴)
            - 점 표기법 (Dot Notation / Property Accessor)
                + . : 객체의 속성에 접근하는 가장 일반적인 방법. 객체 이름 뒤에 점(.)을 찍고 속성 이름을 명시
        - [참고 개념]
            - 도헌쌤 변수 선언 방식
                + 변수를 선언할 때, 해당 함수에 어떤 걸 담을 것인지 예측 가능하도록 초기값을 명시적으로 설정함으로써, 해당 변수의 용도와 데이터 타입을 쉽게 예측할 수 있는 방식을 사용
                    - var name = ''; : 문자열(string)을 담을 변수 > 빈 문자열('') 할당. 
                    - var age = 0; : 숫자(Number)를 담을 변수 -> 0 또는 상황에 맞는 기본 숫자 할당
                    - var object = null; : 객체/DOM 요소를 담을 변수 -> null 할당
                        + tag가 안담긴 상황이 list== null / tag 가 담긴 상황이 되면 list != null 으로 특정 가능
            - 변수 이름이 흐릿하게 나오는 건 변수가 사용된 적이 없다는 것을 나타냄

    > 1_if 
        - [새롭게 배운 개념]
            - 조건문: 특정 조건이 참(true)인지 거짓(false)인지에 따라 다른 코드를 실행하도록 제어하는 구문
                + conditionPart(조건부)가 참이면 내부 logic을 실행하고 거짓이면 건너뜀
                + 비교를 해야하는 대상의 개수가 조건문의 개수와 동일해야 함
                    + 예외: prompt 사용 시 입력하는 주체는 인간이기 때문에 오류 상황을 항상 캐치해야함. 즉 구해야하는 상황은 세 개인 것
                + html, css 코드를 사용하여 잘 제어를 해주어야 js에서 코드를 간결하게 작성할 수 있음
                a. if문(만약에): 가장 기본적인 조건문. 조건이 참일 경우에만 특정 코드 블록을 실행
                b. else문(~이 아닐 때 = 외 나머지 다): 조건이 참일 때 실행될 코드와 거짓일 때 실행될 코드를 모두 지정
                c. else if문(~이 아니라 만약): 여러 조건을 순차적으로 확인하고, 가장 먼저 참이 되는 조건의 코드 블록을 실행. 모든 조건이 거짓이면 else 블록 실행
                d. switch문: 하나의 표현식(변수 등)의 값을 여러 case와 비교하여 일치하는 case의 코드 블록을 실행. else if 문을 대체할 수 있으며, 특정 값과 일치하는지 확인할 때 유용
            - 조건문 실무 사용 예
                1. 로그인 시 아이디와 패스워드가 서버에 저장된 정보와 같은지 비교 후 같다면 승인, 아니라면 오류메세지를 띄운다.

                3. 경품 추첨 시 유저가 뽑은 번호에 따라 경품 당첨 여부를 따질 수 있다.
                4. 삭제 작업 수행시 사용자가 yes를 눌렀을 때와 no 를 눌렀을 때 수행할지 말지를 결정 할 수 있다.
                5. slide 같은 ui component 의 좌, 우 방향으로 최대치로 이동 하였는지 판별 할 수 있다.

            - 게터(getter) 메서드
                : get으로 시작하는 메서드는 주로 객체 내부의 값을 반환하는 역할을 함
            - 생성자 함수 (Constructor Functions) 또는 클래스
                : JavaScript에서 객체를 생성하기 위한 틀 또는 설계도 역할을 하며, 이름의 첫 글자를 대문자로 시작하는 것이 강력한 관례임
                + ex. Date, Array, Object, String, Boolean, Number 등
                + 생성자 함수나 클래스는 그 자체로 많은 속성(데이터)과 메서드(기능)를 포함하며, new 키워드와 함께 사용되어 해당 타입의 새로운 인스턴스(객체)를 만들기도 함
            - 인스턴스(Instance)
                : 클래스나 생성자 함수를 사용하여 new 키워드를 통해 실제로 메모리에 생성된 객체
                + 각 인스턴스는 클래스/생성자 함수에 정의된 구조(속성과 메서드)를 따르지만, 자신만의 고유한 속성 값을 가질 수 있음
                ex. person1 인스턴스의 이름은 "철수", person2 인스턴스의 이름은 "영희"
            - new 연산자
                : 생성자 함수나 클래스 앞에 사용되어 그 설계도를 바탕으로 해당 타입의 새로운 객체 인스턴스(instance)를 생성
                + new를 통해 만들어진 객체들은 같은 설계도(생성자 함수/클래스)를 공유하지만, 각각 자신만의 데이터(속성 값)를 가질 수 있음

    > 2_switch
        - [새롭게 배운 개념]
            - switch
                : 하나의 표현식(값)을 여러 가능한 case 값들과 비교하여, 일치하는 case에 해당하는 코드 블록을 실행하는 제어문. if...else if...else 문을 여러 개 사용하는 것보다 코드를 더 간결하고 가독성 있게 만들 수 있을 때 유용
                + >, <, >=, <=, != 와 같은 연산자를 사용 안 했을 경우 사용
                + switch (key) {
                    case value1:
                    break;

                    case value2:
                    break;

                    default:
                    }
                    + key: switch 키워드 뒤 괄호 안에 오는 값이나 변수. 이 표현식의 결과값이 각 case의 값과 비교됨
                        > ex. 전달: a(var) > key
                        > ex. 변형: a(var) % 2 > key
                    + case 값: 표현식의 결과와 비교될 특정 값. 콜론(:)으로 끝나며, 그 뒤에 실행할 코드가 옴. 값과 타입이 모두 같아야 함
                    + break: 일치하는 case의 코드 블록 실행이 끝나면 switch 문 전체를 빠져나가도록 함. (break는 switch 전유가 아님)
                    + default: 표현식의 값이 어떤 case의 값과도 일치하지 않을 때 실행될 코드 블록을 정의. else와 비슷한 역할을 하며 선택적으로 사용할 수 있음(switch문 내의 어느 위치에나 올 수 있지만, 관례적으로 가장 마지막에 둠)
        - [참고 개념]
            + NaN(Not a Number)
                : NaN은 "숫자가 아님"을 나타내는 특별한 숫자 값. 수학적 오류나 잘못된 숫자 변환 시도 시 발생하며, 연산에 포함되면 결과를 NaN으로 만듦
                + 발생 경우
                    - 숫자로 변환할 수 없는 값을 숫자로 변환하려고 할 때
                        > ex. Number("hello") // NaN
                    - 수학적으로 정의되지 않는 연산을 수행할 때
                        > ex. Infinity * 0 // NaN
                    - 연산 과정에 NaN이 포함될 때
                        > ex. NaN + 5 // NaN

        - [새롭게 배운 개념]
            + for
                : 특정 횟수만큼 코드를 반복해야하는 경우 사용하는 반복문
                + 형태
                    for (초기화; 조건식; 증감식) {
                        반복 실행할 코드
                    }
                    - 초기화: 반복문이 시작될 때 한 번만 실행. 변수를 선언 및 초기화 
                        > ex. var i = 0;
                    - 조건식: 각 반복이 시작되기 전에 평가. 식이 true이면 코드 실행, false이면 반복문 종료 
                        > ex. i < 5;
                    - 증감식: 각 반복이 끝난 후 실행. 주로 변수를 증가시키거나 감소시킴 
                        > ex. i++(세미콜론 사용 X)
                + 코드 반복 순서
                    1. 초기식 실행(var i = 0;)
                    2. 조건식 비교(i < 5;), 조건이 거짓일 경우 반복문 종료
                    3. 참일 경우 이하 코드(로직 ex.console.log(index);) 실행
                    4. 증감부(index++) 실행(반복문에서의 엔진)
                    5. 2단계(반복)
                + 단일 for / 다중  for
                    - 단일 for: 하나의 조건에 따라 코드 블록을 반복 실행
                    - 다중 for: 하나의 for 루프 내부에 또 다른 for 루프가 포함된 구조. 다중 for 루프는 바깥쪽 루프의 한 번의 반복 동안 안쪽 루프가 전체 사이틀을 도는 방식으로 동작하며, 복잡한 패턴이나 2차원적인 구조를 만드는 데 유용하게 사용됨
            + 배열(Array)
                : 여러 값(데이터)을 순차적으로 저장할 수 있는 객체
                + 형태 
                    var arr = ['a', 'b', 'c', 'd', 'e'];
                    - [0, 1, 2, 3, 4 ...] 0번 index부터 순서대로 값을 저장
                + 배열 주요 속성
                    - length: 요소 개수. 즉 데이터의 수량을 의미하는 것과 같음
            + continue / break
                - continue
                    : 반복문 안에서 특정 조건일 때 해당 반복을 건너뛰고 다음 반복으로 바로 넘어가게 하는 키워드. 반복 루프 안에서 예외 케이스를 필터링하고 싶을 때 사용(필터 역할)
                - break 
                    : 반복문, switch문과 같은 제어 구조의 실행을 즉시 중단하고 해당 구조를 빠져나갈 때 사용하는 키워드. 일반적으로 반복문 내에서 특정 조건이 충족되었을 때 루프를 빠져나오게 하는 용도로 사용
                - continue와 break의 차이
                    + continue: 현재 반복을 중단하고 다음 반복 실행
                    + break: 반복문 자체를 완전히 종료
            + confirm
                : 사용자에게 확인 또는 취소의 두 가지 선택지를 제공하는 간단한 대화 상자를 표시하는 데 사용. 사용자의 선택에 따라 true(확인) 또는 false(취소)값을 반환함
                + 동기 처리 방식. 사용자가 응답할 때까지 js코드 실행을 일시 중단시킴
        - [참고 개념]
            + index(i)
                : 배열 안에서 각 요소의 위치를 가리키는 숫자형 주소값
            + ECMAScript(에크마스크립트)
                : 스크립팅 언어의 표준 사양. 여러 웹 브라우저에서 자바스크립트 코드가 일관되게 동작하도록 하기 위해 만들어졌으며, JS는 ECMA의 표준을 따르는 언어라고 볼 수 있음
            + 무한 루프
                : 종료 조건이 충족되지 않아 영원히 또는 프로그램이 강제 종료될 때까지 계속해서 반복 실행되는 루프
                - 경우 
                a. while (true): 항상 참인 조건
                b.  var i = 0; 
                    while (i < 5) {
                        console.log(i); 
                    }: i++;(증감문) 누락되면 i는 항상 0이므로 무한 루프
                c. for (let i = 0; i >= 0; i++): 조건 오류

    > 2_while
        - [새롭게 배운 개념]
            + while
                : 지정된 조건이 참(true)인 동안 코드 블록을 반복적으로 실행
                + 작동 방식
                    1. 루프에 진입하기 전에 condition(조건) 평가
                    2. condition이 true이면, {} 안의 코드 블록 실행
                    3. 코드 블록 실행이 완료되면, 다시 condition을 평가
                    4. condition이 여전히 true이면, 코드 블록 다시 실행. 이 과정 반복
                    5. condition이 false가 되면, 루프는 종료되고 루프 다음 코드 실행
                + 주의사항: while(true)과 같은 무한 반복문을 사용할 때는 반드시 루프를 탈출할 수 있는 조건과 로직(break)을 만들어야 함

        - [새롭게 배운 개념]
            + 함수
                : 특정 작업을 수행하는 코드 블록(중복되는 코드를 하나의 묶음으로 만들고 이름을 붙여, 필요할 때마다 그 이름을 불러다 쓸 수 있게 해주는 도구) 
                + 코드의 재 사용 및 중복 제거, 유지보수의 용이성 등 단순히 코드를 짧게 만드는 것을 넘어, 소프트웨어의 품질을 높이고 개발 효율성을 증대시켜줌
            + 매개변수(Parameter)
                : 함수를 정의할 때 함수가 외부로부터 전달받을 값을 저장하기 위해 선언하는 변수
                + 함수의 선언부
                    - function 함수이름(매개변수1, 매개변수2, ...)의 괄호 안에 위치
                + 함수 내부에 고정된 형태의 값을 넣지 않고 매개변수를 사용함으로써, 함수 내부에서 값을 고정하는 대신 함수를 호출할 때마다 변수 값을 유동적으로 할당할 수 있음
                + 기본적으로 함수는 자신만의 독립적인 작업 공간(스코프)을 가지기 때문에 함수 내에서 선언된 변수에 외부 값이 들어올 수 없으나 매개 변수는 이러한 폐쇄적인 함수에 외부의 데이터를 전달하는 공식적인 '통로' 역할을 해줌
            + 인자/인수(Argument)
                : 함수를 호출할 때 함수에게 실제로 전달하는 값으로 함수 호출문의 괄호 ()안에 위치하며, 함수 정의 시 선언된 매개변수에 순서대로 할당됨
                + 개수 
                    - 일치: 일반적으로 함수 정의 시 선언된 매개변수의 개수와 호출 시 전달하는 인수의 개수를 일치시키는 것이 좋음
                    - 부족: 매개 변수보다 적은 수의 인수를 전달하면, 값을 받지 목한 매개변수는 undefined 값을 갖게 됨
                    - 초과: 매개변수보다 많은 수의 인수를 전달하면, 초과된 인수들은 명시적으로 선언된 매개변수에 할당되지 않고 무시됨(그러나 데이터가 사라지는 것은 아님)
            + 매개변수 vs 인자/인수
                - 매개변수: 함수의 정의 부분. 함수가 받을 값의 자리 표시자 또는 변수 이름.
                - 인자/인수: 함수의 호출 부분. 함수에 실제로 전달되는 값(value).
                - 주로 매개변수는 주차 공간이고, 인수는 그 주차 공간에 주차하는 자동차로 비유
            + (호출부) return
                : return 키워드는 함수가 실행을 마치고 "자신을 불렀던 곳(호출부)"으로 돌아갈 때, 특정 값을 가지고 돌아가도록 하는 명령. 함수 안에서 만들어진 결과물을 함수 바깥 세상으로 꺼내오는 유일한 공식적인 방법.
                ex. function calculateSum(a, b){
                        const sum = a + b;
                        return sum; 
                        // sum 값을 가지고 호출부로 돌아감
                    }

                    const result = calculateSum(10, 20); 
                    // 여기가 호출부. calculateSum(10, 20); 이 부분이 실행되고, 그 자리에 return된 값 30이 남게 됨 그래서 result 변수에는 30이 할당 됨

                    console.log(result); // 출력: 30
                + return의 핵심 기능 
                    1. 값 반환: 함수의 결과물 전달
                        - 함수가 어떤 계산을 하거나, 데이터를 가공하거나, 상태를 확인하는 등의 작업을 수행한 후, 그 결과물을 함수 바깥으로 내보내는 역할을 함
                        - 여기서 결과물은 숫자, 문자열, 불리언 같은 원시 값을 수도 있고, 객체, 배열, 심지어 다른 함수일 수도 있음
                        - 호출한 쪽에서는 이 반환된 값을 변수에 저장하거나, 다른 연산에 사용하거나, 다른 함수의 인자로 전달하는 등 다양하게 활용할 수 있음
                    2. 함수 실행 종료: 함수의 작업 중단 및 제어권 반환
                        - 함수 내에서 return문이 실행되면, return문 이후에 있는 어떤 코드도 실행되지 않으며 그 즉시 해당 함수의 실행은 멈추고 함수의 제어권은 함수를 호출했던 곳으로 되돌아감
                + return을 사용하지 않는다면 
                    : 만약 return을 사용하지 않으면 계산이라는 작업은 수행하지만 결과값을 받을 수 없음(undefined를 반환). 따라서 함수가 어떤 계산을 하거나, 데이터를 가공하거나, 상태를 확인하여 그 결과를 외부에서 사용해야 한다면 반드시 return문을 사용하여 해당 값을 반환해야 함. 그렇지 않으면 함수는 '일만 하고 아무것도 주지 않는 존재'가 되어버리는 것
                + return과 break의 차이점 
                    : return은 함수 자체를 중단시키는데 비해 break는 루프에서 빠져나와 다음 작업을 시작함
                + return문 사용
                    : return문에는 직접적인 값뿐만 아니라, 평가될 수 있는 표현식도 올 수 있음. 그러나 함수는 한 가지 일만 처리하게 해서 역할을 명확하게 하는 것이 좋기 때문에 처리와 출력은 구분해서 작성하는 것이 좋음
