    > [attribute]
    ▪︎ input
    - input은 줄바꿈을 안 함 
    - input focus는 절대 빼지 말 것
    - 대부분의 input 요소는 line-height를 부여했을 때 시각적으로 제대로 적용되지 않는 경우가 있음
    + text, email, search, tel, url: 제한적 적용
    + password: 거의 무시됨
    + number: 제한적
    + button, submit, reset: 적용 가능
    + checkbook, radio: 적용 가능

    ▪︎ line-height 
    - a tag 사용시 메뉴 사이가 좁으면 터치가 힘들기 때문에 line-height를 필히 부여
      + 성인 남성 75px 성인 여성 55-65px
    - 문단 작업시 line-height 꼭 부여해야함
      + 디자이너 또한 마찬가지. 줄간은 오토로 작업하게 두면 안 됨
    - 기본적으로 font는 line-height를 가지고 있으며 각각의 font마다 그 높이가 상이함
      + 대부분의 오차는 5 ~ 10px > 대부분 상하 합 5px 차감 / p 두 개 10px정도 차감
    - a는 개행될 수 있음 그래서 line-height 사용 못 함
