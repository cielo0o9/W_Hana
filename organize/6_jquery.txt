[1_selector]
  - [새롭게 배운 개념]
    - jQuery 선택자(Selector)
      : HTML 문서에서 원하는 요소를 쉽고 빠르게 찾아내는 방법
      - jQuery는 우리가 이미 익숙한 css 선택자 문법을 거의 그대로 사용하기 때문에 쉽게 사용 가능
      - jQuery 선택자의 기본 구조 
        + $("선택자");
          - $: jQuery의 시작을 알리는 기호
          - (""): 괄호 안에 찾고 싶은 요소의 주소(선택자)를 문자열 형태로 입력
          - 이렇게 선택된 결과는 jQuery 객체(Object)로 반환되며, 이 객체에 .css(), .click(), .hide() 같은 다양한 메서드(기능)를 연결하여 요소 조작이 가능해지는 것! 
          - css와 같이 선택자 조합도 가능
    - 선택자 종류
        + 주요 선택자
          - 전체 선택자 ("*"): 페이지의 모든 요소를 선택
          - 태그 선택자 ("div"): 특정 태그 이름을 가진 모든 요소를 선택
          - ID 선택자 ("#Id"): 특정 id 속성을 가진 단 하나의 요소를 선택
          - 클래스 선택자 (".Class"): 특정 class 속성을 가진 모든 요소를 선택
        + 관계 선택자
          - 후손 선택자 ("div p): 띄어쓰기를 이용해 특정 요소의 모든 하위 요소를 선택
          - 자식 선택자 ("ul > li"): 특정 요소의 직계 자식 요소만 선택
          - 인접 형제 선택자 ("h2 + p"): 특정 요소의 바로 다음에 오는 형제 요소 하나를 선택
          - 일반 형제 선택자 ("h2 ~ p"): 특정 요소의 다음에 오는 모든 형제 요소를 선택
        + 속성 선택자
          - $("[속성]"): 특정 속성을 가진 모든 요소를 선택
            ex. $("a[target]") > target 속성이 있는 모든 <a> 태그 선택
          - $("[속성='값']"): 속성과 값이 정확히 일치하는 요소를 선택
            ex. $("input[type='text']") > type이 'text'인 <input> 태그 선택
          - $("[속성!='값']"): 속성값이 일치하지 않는 요소를 선택
            ex. $("input[type!='password']") > type이 'password'가 아닌 <input> 태그 선택
          - $("[속성^='값']"): 속성값이 특정 값으로 시작하는 요소를 선택
            ex. $("a[href^='https']") > href가 'https'로 시작하는 링크 선택
          - $("[속성$='값']"): 속성값이 특정 값으로 끝나는 요소를 선택
            ex. $("img[src$='.png']") > 이미지 경로(src)가 '.png'로 끝나는 이미지 선택
          - $("[속성*='값']"): 속성값이 특정 값을 포함하는 요소를 선택
            ex. $("p[title*='hello']") > title 속성에 'hello'가 포함된 <p> 태그 선택
        + 필터링 선택자
          - :first / :last: 선택된 요소들 중 첫 번째 / 마지막 요소를 선택
            ex. $("li:first") > 모든 <li> 중 첫 번째 <li>
          - :eq(index): 선택된 요소들 중 특정 순서에 있는 요소를 선택
            ex. $("li:eq(2)") > 모든 <li> 중 세 번째 <li> (인덱스는 0, 1, 2)
          - :even / :odd: 짝수 / 홀수 번째 요소를 선택 (0부터 시작)
            ex. $("tr:even") > 테이블의 짝수 번째 행(0, 2, 4...) 선택
          - :gt(index) / :lt(index): 특정 순서보다 크거나(gt) 작은(lt) 인덱스를 가진 요소들을 선택
            ex. $("li:gt(1)") > <li> 중 인덱스 1번(두 번째)보다 큰 요소들(세 번째부터 끝까지) 선택
          - :not(선택자): 특정 선택자를 제외한 나머지 요소를 선택
            ex. $("input:not(:checked)") > 체크되지 않은 모든 <input> 요소 선택
        + 폼 선택자
          - :input: 모든 <input> 요소를 선택
            + <textarea>, <select>, <button> 가능
          - :text, :password, :radio, :checkbox, :submit, :file 등
          - :enabled / :disabled: 활성화 / 비활성화된 폼 요소를 선택
          - :checked: 체크된 radio 버튼이나 checkbox를 선택
          - :selected: <select> 옵션 중 선택된 <option>을 선택
    - .css() 메서드 사용법
      a. css("속성명"): 해당 속성 값을 가져옴
      b. css("속성명", "값"): 해당 속성 값을 설정
      c. css({ "속성1":"값1", "속성2":"값2" }): 여러 속성을 한 번에 설정
      + 여러 css 속성을 변경해야 할 때 .css()번 호출하는 것보다 중괄호 {}를 사용해 object type으로 변환 후 전달하는 것이 효율적이고 가독성도 좋음
  - [참고 개념]
    + jquery 로 변수를 사용할 때는 jquery 변수임을 알아볼 수 있는 이름을 부여할 것 ex. $divs

[2_targetMove]
  - [새롭게 배운 개념]
    + init
      : initialization의 줄임말로, 초기화를 의미
    + .val() 메서드
      : HTML Form 요소의 value 속성 값을 가져오거나(Get) 설정하는(Set) 데 사용되는 전용 메서드
      - 값 가져오기 (Getter)
        : 메서드를 괄호 안에 아무것도 넣지 않고 호출하면, 현재 선택된 폼 요소가 가지고 있는 value 값을 읽어서 반환
      - 값 설정하기 (Setter)
        : 메서드의 괄호 안에 특정 값을 넣어서 호출하면, 선택된 폼 요소의 value 값을 해당 값으로 변경하거나 설정 
    + e(이벤트 객체)
      : 웹 페이지에서 어떤 사건(이벤트)이 발생했을 때, 그 사건에 대한 상세한 정보를 담고 있는 일종의 보고서. 
        > 여기서 사건이란 사용자의 행동, 예를 들어 마우스 클릭, 키보드 누름, 스크롤 등을 의미
      - 이벤트 핸들러 함수가 호출될 때 브라우저는 이 객체를 함수의 첫 번째 매개변수로 자동으로 넘겨주는 것.(보통 이 매개변수를 e 또는 event라는 이름으로 받아서 사용)
  - [참고 개념]
    + jquery 는 궁금한 게 생기면 google에 영어로 검색할 것

[3_addRemoveToggle]
  - [새롭게 배운 개념]
    + .attr("type", "text")
      : .attr()은 HTML 요소의 속성(attribute)을 읽거나 변경해주는 메서드
      - .css() 메서드와 같이 .attr() 또한 인자가 하나면 값을 읽어오고(Getter), 두 개면 값을 설정(Setter)하는 동일한 패턴을 가짐!
      - .attr('src', 'new_image.jpg')처럼 사용하여 이미지도 동적으로 바꿀 수 있음
      + 비밀번호 toggle 핵심 원리
        : <input type="password"> 태그의 type 속성을 text로 바꾸면 브라우저는 이 입력창을 일반 텍스트 필드로 취급하여 입력된 내용을 보여주고, 다시 password로 바꾸면 ****처럼 가려주는 것
    + .text() 메서드
      : 선택한 요소 내부의 텍스트를 읽거나 변경
      - $checkTarget.text(): 태그 안의 글자(아이콘 이름)를 가져옴
      - $checkTarget.text("다른글자"): 태그 안의 글자를 "다른글자"로 바꿈
    + status 변수
      : 현재 체크박스가 '체크된 상태'인지 '체크 안 된 상태'인지 기억하기 위한 변수. 동적 요소를 만들 때 중요한 개념. false는 '체크 안 됨', true는 '체크됨'을 의미
      - checkStatus = !checkStatus; (상태 반전)
        : toggle의 핵심 로직. 클릭할 때마다 checkStatus의 값을 반대로 뒤집음.
  - [참고 개념]
      + 이번 수업의 핵심은 동적 요소의 흐름을 배우는 것이며, 작동 전/후 속성들은 css에 준비해둔 상태. 또한 이 수업은 기본 기능을 가지고 있는 태그들(input 등)을 사용하지 않고 구현했을 때 수습하는 과정이기도 함

[4_foldUI]
  - [새롭게 배운 개념]
    + .eq() 메서드
      : .eq()는 equals(같다)의 줄임말로, 여러 개의 요소가 선택된 그룹에서 특정 순번(index)에 해당하는 단 하나의 요소를 정확히 골라내는 메서드
     - .eq()의 주요 특징 및 사용법
      1. 제로베이스 인덱싱(Zero-based Indexing): 0부터 시작하는 순번. 가장 중요한 규칙
      2. 음수 인덱스 사용 가능: 마지막 요소를 찾기 위해 전체 개수를 셀 필요 없이 .eq(-1)만 사용하면 끝에서부터 역순으로 count. .eq()의 매우 편리한 기능 중 하나.
      3. 반환값은 jQuery 객체: .eq()를 사용해서 요소를 골라내면, 그 결과물은 순수한 HTML 요소가 아니라 jQuery의 기능으로 포장된 jQuery 객체가 되는 것
        + 이 말은 즉슨, 결과물에 바로 이어서 .css(), .addClass(), .click() 같은 다른 jQuery 메서드를 연결해서 사용(체이닝)할 수 있다는 것
